# IEEE Style Manual - Section Order

From the IEEE Editorial Style Manual for Authors (Updated 29 July 2024):

The correct order is:
1. Introduction
2. Body of Article
3. Conclusion
4. **Appendix(es)**
5. Acknowledgment
6. **References**
7. Photographs and Biographies

So: Appendix comes BEFORE References in IEEE format.

Current paper already has this order (appendix before references), which is correct.
The issue was just that `\clearpage` caused Table 5 to float to a separate page.
